# Объясни ошибку

**Автор:** Назаренко Илья Сергеевич, группа M3114
**IDE:** Visual Studio Code

## Описание

Плагин для VS Code, который объясняет ошибки C++ простым языком.

## Возможности

- Автоматически находит ошибки компиляции C++ в терминале и предлагает их объяснить
- Объяснение по выделенному тексту ошибки (`Cmd+Option+E` / `Ctrl+Alt+E`)
- Для каждой ошибки показывает: что случилось, почему так бывает, как исправить
- Новые ошибки легко добавить в `src/errors.json`

## Как пользоваться

- Скомпилируй код в терминале. При ошибке появится уведомление, нажми «Объяснить».
- Или выдели текст ошибки и нажми `Cmd+Option+E` или `Ctrl+Alt+E` на Windows.

## Установка

1. Скачай файл `.vsix` из раздела [Releases](../../releases)
2. В VS Code открой Extensions `Cmd+Shift+X` **Install from VSIX...**
3. Выбери скачанный файл

## Как добавить ошибку

Допиши блок в `src/errors.json`:

```json
{
  "id": "my_error",
  "pattern": "текст ошибки",
  "title": "Заголовок",
  "what": "Что случилось",
  "why": "Почему",
  "fix": ["Как исправить"]
}
```

## Запуск из исходников

```
npm install
npm run compile
```

Затем нажми `F5`.
